# SoccerBot
meslsoccerbot is a KiCad 10 project for an autonomous soccer robot. It features an ESP32-C3-DevKitM-1 for Wi-Fi logic, a TB6612FNG H-bridge for dual DC motor control, and an LM2596S-5 buck converter converting high-current XT60 battery inputs to a stable 5V 3A rail. The 164x145mm 2-layer board uses M3 mounts and heavy GND shielding.
